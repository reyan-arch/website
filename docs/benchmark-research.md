# IRG competitor pattern review

Accessed **3 October 2026**. The twenty primary destinations in the supplied brief were reopened during this implementation session. This review records readable page structure and public content, not measured visual performance, independent verification of competitor results or a claim that their services match IRG’s scope.

The user’s latest direction is to **edit the existing live IRG website**, preserving its photographic hero, header/navigation structure, page composition and animations. The adaptations below should be applied inside that existing experience. Page additions may use that same established visual system when authorised. The latest sector clarification calls for Travel, Hospitality and Lifestyle scroll sections on Services, rather than separate sector/country/city routes. The reference patterns do not substantiate new IRG capabilities or authorise copied language.

## Application rules

These references support information-design decisions. Competitor marketing statements were not independently audited and should not be treated as substantiation for IRG.

The reviewed IRG copy, case definitions and publication boundaries are recorded in [content-review.md](content-review.md). Typography, colour, imagery and interaction changes should retain the current live site’s recognisable structure. Related links should use the established routes and precise section anchors; a useful connection is more valuable than a large link count.
